LaunchConfiguration 不是字符串

LaunchConfiguration('robot_name') 是一个「替换值」，在 launch 真正执行时才求值。不能对它做 Python 字符串操作（如 + 或 if x == 'true'）。需要拼接时用列表 ['prefix_', robot_name]，需要判断时用 IfCondition / PythonExpression，复杂逻辑用 OpaqueFunction。

6.10 调试 launch

自测题

1. ros2 launch my_first_nodes demo.launch.py 报 “file 'demo.launch.py' was not found”，最常见原因？
launch 文件没有被安装：Python 包的 setup.py 中 data_files 没加 launch 目录，或 C++ 包没写 install(DIRECTORY launch ...)；也可能修改后没有重新构建 / source。
2. 在 launch 中写 if LaunchConfiguration('debug') == 'true': 为什么不起作用？
LaunchConfiguration 是延迟求值的对象，在 generate_launch_description() 运行时还没有值，比较结果永远是 False。应使用 IfCondition 或在 OpaqueFunction 中用 perform(context) 获取真实值。
3. parameters 列表中同时有 YAML 和字典，同名参数以哪个为准？
列表中靠后的覆盖靠前的。[params_file, {'robot_name': ...}] 中字典的值生效。
