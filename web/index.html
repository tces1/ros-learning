前置知识

知识需要程度说明

Git推荐clone / commit / branch，用于管理你的工作空间

你的电脑推荐方案评价

本教材的约定

  • 命令前没有提示符，直接复制到终端运行；需要在新终端运行时会明确说明。
  • 工作空间统一放在 ~/ros2_ws。
  • 代码块右上角有「复制」按钮；带文件名的代码块表示要写入该路径的文件。
  • 彩色提示框含义：绿色是技巧，黄色是易错点，红色是会导致故障的错误，蓝色是补充知识。
  • 每章结尾有自测题（点击展开答案）和可勾选的自查清单，勾选状态会自动保存。
