附录 A　常见问题排查

按「现象 → 原因 → 解决」整理学习过程中最常遇到的问题。遇到报错时先在本页搜索（Ctrl+F）关键词。

A.1 环境与安装

现象原因解决
ros2: command not found未 source ROS 环境source /opt/ros/jazzy/setup.bash，并写入 ~/.bashrc
apt 安装时报依赖冲突、“held broken packages”系统包未升级先 sudo apt update && sudo apt upgrade 再安装
rosdep update 超时访问 GitHub 受限使用代理或 rosdepc
RViz / Gazebo 窗口打不开（WSL）图形驱动问题wsl --update；尝试 export LIBGL_ALWAYS_SOFTWARE=1
编译时 WSL 卡死或被杀内存不足colcon build --parallel-workers 1；在 %UserProfile%\.wslconfig 中增加 memory=8GB 与 swap
混用 Humble 与 Jazzy 的包同时 source 了两个发行版检查 ~/.bashrc，一个终端只 source 一个发行版

A.2 构建与运行

现象原因解决
Package 'xxx' not found未 source 工作空间 / 构建失败 / 在错误目录构建在 ~/ros2_ws 构建，source install/setup.bash
No executable found入口未注册或未安装Python：setup.py 的 console_scripts；C++：install(TARGETS ... DESTINATION lib/${PROJECT_NAME})
launch / yaml 文件找不到未安装到 share 目录Python 包在 data_files 加入；C++ 包 install(DIRECTORY ...)
改了代码不生效没重新构建，或 source 的是旧 install重新 build 并 source；Python 用 --symlink-install
ModuleNotFoundError: No module named 'my_interfaces'接口包未构建或未在 package.xml 声明依赖先构建接口包，添加 <depend>my_interfaces</depend>
CMake：Could not find a package configuration file provided by "xxx"依赖未安装rosdep install --from-paths src --ignore-src -y 或 sudo apt install ros-jazzy-xxx（下划线换成短横线）
自定义消息报错 “field name must be lowercase”字段命名不规范字段用 snake_case，常量全大写
setup.py install is deprecated 警告setuptools 版本提示可忽略，不影响使用

A.3 通信

现象原因解决
话题存在但订阅回调不触发QoS 不兼容ros2 topic info -v 对比；传感器话题用 qos_profile_sensor_data
两台电脑互相看不到节点Domain ID 不同、防火墙、不同网段、组播被禁统一 ROS_DOMAIN_ID；开放 UDP 7400–7600；检查 ROS_AUTOMATIC_DISCOVERY_RANGE；必要时用 ROS_STATIC_PEERS
看到了别人的话题同网段同 Domain修改 ROS_DOMAIN_ID
ros2 topic list 结果不全或滞后ROS 2 daemon 缓存ros2 daemon stop && ros2 daemon start
服务调用卡住不返回在回调中同步等待服务响应导致死锁用 call_async + 完成回调，或独立回调组 + 多线程执行器（第 5 章）
Parameter not declared使用前未声明先 declare_parameter
Twist 发出去但机器人不动话题名或类型（Twist / TwistStamped）不匹配ros2 topic info -v /cmd_vel 看订阅者类型

A.4 TF 与时间

现象原因解决
"xxx" passed to lookupTransform argument target_frame does not exist坐标系未发布或拼写错误view_frames 检查；frame_id 不要以 / 开头
Lookup would require extrapolation into the futureTF 延迟、时间源不一致所有节点统一 use_sim_time；查询加 timeout；用 Time() 获取最新变换
extrapolation into the past数据太旧或时间源不一致同上；检查 bag 回放是否用了 --clock
TF 树断成两截缺少某个发布者（如 robot_state_publisher、里程计）view_frames 找到断点
机器人在 RViz 中抖动 / 跳变两个节点发布同一变换view_frames 查看每条边的发布者
RViz 中数据不显示、报 “Message filter dropping message”Fixed Frame 与数据坐标系之间没有变换，或时间戳问题检查 Fixed Frame 和 TF；检查 use_sim_time

A.5 仿真

现象原因解决
模型没出现robot_description 为空、xacro 错误、spawn 失败看 create 节点输出；手动运行 xacro 检查
模型抖动、弹飞惯性不合理、碰撞体重叠按公式计算惯性；检查碰撞体与地面不重叠
小车不动桥接方向错误；仿真暂停；插件关节名错误gz topic -l；启动时加 -r；核对关节名
激光无数据世界缺少 Sensors 系统插件在 world 中加入 gz-sim-sensors-system
仿真非常慢（实时因子很低）软件渲染、物理步长太小、模型复杂使用 GPU；简化碰撞体；无界面运行 -s

A.6 导航

现象原因解决
Nav2 一直等待、不激活AMCL 未收到初始位姿；TF 缺失RViz 设置 2D Pose Estimate；参数 set_initial_pose: true
“Failed to create plan”目标 / 起点在障碍或膨胀区内检查初始位姿；减小 inflation_radius；目标放在空旷处
“Robot is out of bounds of the costmap”定位错误或代价地图尺寸太小重新设置初始位姿；检查全局代价地图
机器人在原地打转目标容差太小、控制器参数不当放宽 goal checker 容差
代价地图上没有障碍物激光 QoS、话题名、frame 或 obstacle_max_range 设置错误检查 observation_sources 配置
建图有重影里程计不准、转弯太快放慢速度；检查轮距、轮径参数

A.7 求助的正确方式

在论坛或 Robotics Stack Exchange 提问时，请提供：

  1. ROS 发行版、Ubuntu 版本、是否在 WSL / 虚拟机中
  2. 完整的报错文本（不要截图，贴文字）
  3. 最小复现步骤与相关代码 / launch / 参数
  4. 你已经尝试过的排查步骤与结果（ros2 topic info -v、view_frames 等输出）
