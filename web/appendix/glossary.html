附录 D　术语表

按类别整理的 ROS2 常见术语。括号内为首次详细介绍的章节。

D.1 核心概念

术语解释
Node 节点完成单一职责的程序单元（第 1、3 章）
Topic 话题发布 / 订阅式的异步数据流（第 4 章）
Service 服务一次请求、一次响应（第 5 章）
Action 动作带反馈、可取消的长时任务（第 5 章）
Parameter 参数节点的可配置项（第 5 章）
Interface 接口msg / srv / action 类型定义的统称（第 4 章）
Executor 执行器调度回调执行的组件（第 4 章）
Callback Group 回调组控制回调能否并行执行（第 4 章）
Namespace 命名空间名字前缀，用于隔离多实例（第 2、6 章）
Remapping 重映射启动时修改话题 / 服务 / 节点名（第 6 章）
Lifecycle Node 生命周期节点带标准状态机的节点（第 2 章）
Component 组件可加载到容器进程中的节点，支持进程内通信（第 2、6 章）

D.2 中间件与通信

术语解释
DDSData Distribution Service，ROS2 默认使用的发布 / 订阅中间件标准（第 2 章）
RMWROS MiddleWare 接口，隔离 ROS 与具体中间件实现
Zenoh另一种通信中间件，Kilted 起为官方一级支持
QoSQuality of Service，服务质量策略（第 4 章）
Domain ID通信域编号，不同域互不可见
LatchingROS1 中“锁存”最后一条消息，ROS2 对应 TRANSIENT_LOCAL
Intra-process 进程内通信同一进程内节点间传递指针，避免序列化

D.3 构建与工程

术语解释
Workspace 工作空间包含 src / build / install / log 的目录（第 2 章）
Package 包代码组织与构建的最小单位
amentROS2 的构建系统（ament_cmake / ament_python）
colcon多包构建工具（第 10 章）
rosdep依赖安装工具（第 10 章）
vcstool多仓库管理工具（第 10 章）
Underlay / Overlay叠加的环境层，overlay 覆盖 underlay 中的同名包
Bringup启动整个机器人系统的 launch 与配置集合
Distro 发行版如 Humble、Jazzy（第 1 章）
REPROS Enhancement Proposal，社区约定文档，如 REP-103（单位与坐标）、REP-105（移动机器人坐标系）

D.4 坐标与建模

术语解释
TF / TF2坐标变换库（第 7 章）
Frame 坐标系TF 树中的节点，如 map、odom、base_link
Quaternion 四元数姿态表示 (x, y, z, w)，必须归一化
Euler Angles 欧拉角roll / pitch / yaw
Optical Frame 光学坐标系相机坐标约定：z 前、x 右、y 下
URDF机器人描述格式（第 8 章）
XacroURDF 的宏语言
SDFGazebo 使用的仿真描述格式（第 9 章）
SRDFMoveIt 的语义描述：规划组、命名位姿、ACM（第 14 章）
Link / Joint连杆 / 关节
Inertia 惯性张量描述刚体转动惯性的 3×3 矩阵

D.5 导航与控制

术语解释
Odometry 里程计由轮速 / IMU 等推算的位姿，连续但会漂移
SLAM同时定位与建图（第 13 章）
AMCL自适应蒙特卡洛定位，基于粒子滤波
Occupancy Grid 占据栅格二维栅格地图
Costmap 代价地图带代价值的栅格地图，用于规划和避障
Inflation 膨胀在障碍物周围增加代价，使机器人与障碍保持距离
Footprint机器人在地面上的轮廓多边形
Global Planner 全局规划器计算从起点到终点的完整路径
Controller 局部控制器跟踪路径并实时避障，输出速度指令
Behavior Tree 行为树Nav2 编排任务的方式
Recovery 恢复行为卡住时执行的旋转、后退、清图等
EKF扩展卡尔曼滤波，常用于融合轮速与 IMU（robot_localization）
Hardware Interface 硬件接口ros2_control 中读写硬件的插件（第 12 章）
Controller Managerros2_control 中管理控制器与实时循环的组件

D.6 机械臂与感知

术语解释
FK / IK正 / 逆运动学（第 14 章）
Planning Group 规划组一起规划的一组关节
Planning Scene 规划场景机器人状态 + 环境碰撞物体
ACMAllowed Collision Matrix，允许碰撞矩阵
OMPL开源运动规划库，MoveIt 默认规划器
Cartesian Path 笛卡尔路径末端沿指定几何路径（如直线）运动
Intrinsics 内参相机焦距、主点、畸变（第 15 章）
Extrinsics 外参传感器相对机器人的安装位姿（即 TF）
Point Cloud 点云三维点的集合
Voxel 体素三维栅格单元，用于降采样或三维代价地图
rosbag / MCAP数据录制工具 / 推荐的存储格式（第 11 章）

D.7 机器人测试

术语解释
Test Oracle 测试预言判断测试通过或失败的依据，如容差、不变量、基准（T1、T5）
SIL / HIL软件在环 / 硬件在环：真实软件 + 仿真环境 / 真实控制硬件 + 仿真或台架负载（T1、T7）
Component Test 组件测试在测试进程内创建节点，直接驱动回调或用假依赖替代外部系统（T2）
Fake / Stub / Mock假实现 / 固定返回值的桩 / 预设并验证调用的模拟对象（T2）
Property-based Testing 性质测试描述对任意输入都成立的性质，由工具自动生成输入，如 hypothesis（T2）
launch_testingROS2 官方集成测试框架，用 launch 启动被测进程并断言其行为（T3）
Flaky Test 不稳定测试代码不变、结果时过时不过的测试，常因 sleep、发现时序、隔离不足引起（T3）
Scenario Test 场景测试在仿真中运行完整系统，按场景定义自动判定成败（T4）
RTF 实时因子仿真时间流逝速度与真实时间之比（T4）
Golden Master 基准对比与人工确认过的历史输出逐项比较的回归测试（T5）
Invariant 不变量任何时候都必须成立的规则，如「前方过近时不得前进」（T5）
Soak Test 长稳测试长时间连续运行，发现泄漏、累积误差、偶发崩溃（T6）
Fault Injection 故障注入主动制造进程崩溃、传感器中断、网络劣化等故障，验证系统反应（T6）
Fail-safe / Fail-open失效时进入安全状态 / 失效时按正常放行（T2）
MDBF / MTBF平均故障间隔里程 / 时间（T1、T7）
Pairwise 成对组合测试保证任意两个因素的每对取值至少出现一次的用例组合方法（T7）
Entry / Exit Criteria 准入 / 准出条件开始测试 / 允许发布前必须满足的条件（T7）
